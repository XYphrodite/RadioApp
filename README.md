# RadioWork // FM (.NET 10 Blazor Hybrid)

Настоящее **живое FM-радио** (не плейлист-плеер!) на **.NET 10 MAUI Blazor Hybrid** (Windows + Android) и стриминг-сервере **ASP.NET Core Minimal API**, вещающее по собственной GPU-индексированной фонотеке (`Discogs-400 EffNet`).

## Особенности эфира

- **Непрерывная шкала времени на всех 11 частотах одновременно (`87.5–108.0 MHz`)** — эфир привязан к реальному времени (`UTC` + фаза станции). При переключении с `104.5 Nightdrive FM` на `88.7 Westside FM` вы попадаете ровно в ту секунду трека, которая звучит на волне прямо сейчас, без возможности перемотки (`🔒 Прямой эфир`).
- **3 способа настройки частоты**:
  1. Интерактивная шкала FM-тюнера (`drag` мышью/пальцем или прокрутка колесом мыши) с синтезированным Web Audio FM-шорохом.
  2. Живое табло всех 11 радиостанций справа (сортировка по размеру базы или по частоте `MHz`).
  3. Круговое **Колесо станций** в духе GTA (`Q` или кнопка `◎ Колесо станций`).
- **Управление ротацией вместо плейлистов**:
  - `⏻ В ЭФИРЕ / MUTE` (`Space`) — приглушает приёмник, пока эфир продолжает идти в реальном времени.
  - `♥ Чаще в эфире` — повышает вес трека (`2×`) в детерминированной ротации волны без прерывания текущего воспроизведения.
  - `✕ В бан` — навсегда убирает трек из ротации станции и переводит эфир на следующий трек.
  - `⚡ Помехи (след.)` — сбрасывает текущий трек на волне через радиопомеху.
- **Lossless-стриминг на ПК и мгновенный старт на телефоне**:
  - Прямая отдача `FLAC`, `MP3`, `OGG`, `WAV`, `AAC` через `HTTP 206 Partial Content` на десктопе и потоковый ремультиплекс `ALAC (.m4a)` в lossless `FLAC`.
  - На Android — мгновенный поток `Opus 192 kbps` с серверным смещением `-ss`, локальным кэшем каталога (`ETag` / `304`) и бесшовной предзагрузкой следующего трека.
  - Автоматическая подгрузка и сжатие обложек альбомов (внешних `cover.jpg` или встроенных в аудиофайл) на яблоко вращающегося винила.

- **Android со вшитым Tailscale (`tsnet-bridge`)**:
  - Работает полностью в `userspace` поверх HTTPS DERP (`TCP 443`, `MTU 1200`) **без системного `VpnService`-слота** — не конфликтует с активным сторонним VPN (Happ, VLESS/Xray и др.).
  - Авторизация в 1 тап через браузер (`🔑 Войти в Tailscale`) с сохранением сессии и автоматическим резолвом пира радиосервера через локальный loopback-мост `127.0.0.1`.
  - Поддержка системного медиаплеера шторки / экрана блокировки Android и гарнитуры (`MediaSession`: обложка, трек, переключение волн `⏮` / `⏭`).

## Состав решения (`RadioApp.slnx`)

- `src/RadioApp.Core` — модели каталога, пользовательское хранилище `UserRadioStore` и движок синхронного вещания `RadioBroadcastEngine`.
- `src/RadioApp.Server` — лёгкий `.NET 10` аудио/каталог сервер (`GET /api/health`, `/api/stations`, `/api/stream/{id}`, `/api/cover/{id}`).
- `src/RadioApp.Maui` — клиентское приложение `.NET 10` MAUI Blazor Hybrid (`net10.0-windows10.0.19041.0` + `net10.0-android`).
- `tools/tsnet-bridge` — Go/`gomobile` модуль вшитого userspace-клиента Tailscale (`tsnet.aar`).
- `tests/RadioApp.Tests` — модульные тесты `xUnit`.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Space` | Включить / приглушить приёмник (`В ЭФИРЕ` / `MUTE`) |
| `Q` | Открыть / закрыть круговое Колесо станций |
| `←` / `→` | Предыдущая / следующая частота FM |
| `Esc` | Закрыть Колесо станций / окно настроек |
